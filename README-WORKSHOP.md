# AI voor leerkrachten — technische proef

Afzonderlijke lokale kopie van arcadiascholen/ai-leerlijn. De oorspronkelijke remote is verwijderd om onbedoeld terugschrijven te voorkomen. De oorspronkelijke GPL-3.0-licentie en vormgevingsbronnen blijven behouden.

Uitgewerkt: startpagina, vaste navigatie, behoefte, bestaande promptcomponent met kopieerfunctie, URL per stap, toetsenbordnavigatie en lokaal onthouden van de huidige stap. Andere workshopstappen zijn expliciet gemarkeerde plaatshouders. De oorspronkelijke leerlingmodules zijn nog in de bron aanwezig en worden voor de definitieve publicatie verwijderd.

Ontwikkelen: `npm ci`, `npm run dev`. Open `/vibecoding-voor-leerkrachten/`. Controleren: `npm run check` en `npm run build`.

Voor GitHub: maak een nieuw project `vibecoding-voor-leerkrachten`, voeg dat als remote toe en stel Settings > Pages > Source in op GitHub Actions. De bestaande workflow is aanwezig en de Astro-base is aangepast. Nog niet online gepubliceerd.
